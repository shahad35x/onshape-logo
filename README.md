# Logo Design


## Steps
1. Selected a reference logo 
2. Sketched half of the shape using Line and Spline tools.
3. Used the Mirror tool with a vertical construction line to create the symmetric other half.
4. Added a 4mm circular hole near the wing tip as a keychain opening.
5. Extruded the full sketch by 2mm to create a solid part.
6. Exported the final model as an STL file.


## Files
- `task-2m.stl` – Final 3D printable keychain design
